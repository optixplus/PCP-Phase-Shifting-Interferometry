# Principal Component Pursuit for Phase-Shifting Interferometry (PCP-PSI)

This repository provides a MATLAB implementation of **principal component pursuit for phase-shifting interferometry (PCP-PSI)**, a framework for identifying distorted interferograms and recovering phase in the presence of frame disturbances, defective pixels, and Gaussian noise.

The framework is described in the manuscript **“Decoupling Signal from Sparse Noise and Dynamic Perturbations: A Unified Principal Component Pursuit Framework for Disturbance-Immune Phase-Shifting Interferometry.”** PCP-PSI serves as a preprocessing stage: it suppresses sparse corruptions and screens disturbed frames before phase retrieval. The included demonstration uses PCA followed by iterative least-squares fitting for the retrieval stage.

---

## 📌 Overview

Under the ideal PSI model, each frame is a linear combination of three spatial patterns: the background, the cosine-modulated phase, and the sine-modulated phase. Stacking the vectorized frames as matrix columns therefore gives an ideal interferogram matrix with rank at most three.

PCP-PSI uses this structure to model an observed interferogram matrix as a low-rank component plus sparse deviations. Principal component pursuit (PCP) estimates these components using an augmented Lagrange multiplier (ALM) iteration:

$$
\min_{L,S} \|L\|_* + \lambda\|S\|_1
\quad \text{subject to} \quad X = L + S.
$$

Here, $X$ is the observed interferogram matrix, $L$ is its low-rank component, and $S$ captures sparse deviations. The nuclear norm $\|L\|_*$ promotes low rank, while the elementwise norm $\|S\|_1$ promotes sparsity.

The script detects distorted frames from the column energies of $S$ using a median-based outlier rule. It then retains the corresponding stable columns of $L$, estimates the phase and phase-shifting angles with principal components analysis (PCA), and refines both estimates with iterative least-squares fitting.

Isolated entries of $S$ model defective-pixel or salt-and-pepper errors, while high-energy columns can indicate dynamically distorted frames. This separation relies on sufficiently sparse corruption and a low-rank signal whose singular vectors are not concentrated on a few pixels or frames. Dense Gaussian noise falls outside the sparse-corruption model; the thresholding operations may partially attenuate it, but complete removal is not guaranteed.

## 📂 Included Method

### 1. PCP-PSI Demonstration (`PCP_PSI.m`)

The script:

1. Simulates phase-shifting interferograms with randomly tilted frames, Gaussian noise, and randomly saturated pixels.
2. Decomposes the interferogram matrix into low-rank and sparse components through singular-value and elementwise soft thresholding.
3. Identifies distorted frames from the sparse-component energy and excludes them from phase retrieval.
4. Applies PCA to the retained low-rank frames to initialize the phase and phase-shifting angles.
5. Refines these estimates through five iterations of least-squares fitting.
6. Prints the simulated and detected distorted-frame indices and displays the decomposition and wrapped-phase results.

All simulation data are generated by the script; no external dataset is required.

The manuscript evaluates the framework through parameter sweeps and a Michelson-interferometer experiment. This repository contains the single simulated demonstration above. Experimental recordings, sweep drivers, and PSNR/SSIM evaluation scripts are not included.

## ⚙️ Requirements

* MATLAB with support for `isoutlier` and `clim`.
* The implementation uses MATLAB matrix operations, `svd`, `eig`, and plotting functions; it does not call an external PCP solver.

## 🚀 Usage

From a terminal in the directory where you want to store the repository, run:

```bash
git clone git@github.com:optixplus/PCP-Phase-Shifting-Interferometry.git
cd PCP-Phase-Shifting-Interferometry
```

Open MATLAB and set its current folder to the cloned `PCP-Phase-Shifting-Interferometry` directory. In the MATLAB Command Window, run:

```matlab
rng(0);
PCP_PSI
```

Setting the random seed makes repeated runs reproducible in the same MATLAB environment. The script clears workspace variables and generates a fresh simulation on each run.

### Simulation Parameters

Edit the parameters near the beginning of `PCP_PSI.m`:

| Parameter | Default | Meaning |
| --- | --- | --- |
| `Nx`, `Ny` | `256`, `256` | Image dimensions in pixels |
| `N` | `20` | Number of interferograms |
| `DeltaStep` | `pi/3` | Nominal phase-shifting step in radians |
| `DistortedFrameRatio` | `0.15` | Fraction of frames with simulated tilt disturbances |
| `DefectivePixelRatio` | `0.02` | Fraction of pixels set to zero or one in each frame |
| `SNRGaussian` | `15` | Gaussian-noise SNR in dB, before intensity clipping |

The manuscript's Figure 1 uses a Gaussian-noise SNR of **25 dB**. Set `SNRGaussian = 25` in the script to use that nominal noise setting; the other parameters in the table already match its stated image size, frame count, nominal phase step, defective-pixel ratio, and distorted-frame ratio. Exact random realizations and quantitative evaluations require the corresponding simulation data and evaluation procedures.

The PCP iteration uses a relative reconstruction-residual tolerance of `1e-6` and at most `100` iterations. The console reports whether it reaches the tolerance before the iteration limit.

### Inspecting the Results

* Compare `Setting Distorted Frames` and `Recognized Distorted Frames` in the Command Window.
* Inspect the observed matrix $X$, low-rank component $L$, and sparse component $S$ for a retained frame and, when detected, a distorted frame.
* Compare the simulated wrapped phase with the retrieved wrapped phase in the figure.
* Inspect `StableFrameIndex`, `DistortedFrameIndex`, `PhiRetrieval`, and `Delta_LSM` in the MATLAB workspace. `Delta_LSM` contains estimates for the retained frames only.

Detection and reconstruction depend on the simulated disturbances and noise. The least-squares stage requires at least three retained frames with sufficiently diverse phase shifts. The output is a wrapped phase map; the script does not perform phase unwrapping or report a phase-error metric.
